Frequently Asked Questions

Why is IS 10262 not used for Geopolymer, UHPC, or ECC?

Indian Standard IS 10262:2019 was formulated empirically for conventional Portland cement hydration (OPC, PPC, PSC). Advanced special concretes follow completely different chemical and physical mechanisms:

  • Geopolymer: Involves polycondensation of aluminosilicate gel activated by concentrated alkalis (8–16M NaOH + Na2SiO3), not water-cement hydration.
  • UHPC: Operates at w/b ≤ 0.22 with fine particles under 0.6 mm, bypassing traditional coarse aggregate proportioning.
  • ECC: Governed by steady-state crack bridging micromechanics and PVA fiber volume fractions rather than standard compressive strength charts.

All special concretes are served as literature reference-based proposals anchored to published benchmarks, carrying mandatory trial mix warnings.

What do the Amber vs Green verification badges mean?

Every special mix in the library carries a verification badge:

Literature Reference (Unverified) Verified Benchmark

Unverified mixes are literature-derived baselines requiring initial laboratory batching. Administrators can promote records to Verified once physical lab test data or peer-reviewed batch results are confirmed.

Does this mix design platform use an external LLM API?

No. There is zero runtime dependence on external generative LLM APIs (OpenAI, Gemini, Claude, etc.). Parameter parsing uses deterministic regex matchers and keyword bank scoring (1,200+ phrases), RAG retrieval uses hybrid BM25 and local TF-IDF embeddings, and calculations run on verified offline Python engines.

Can calculated proportions be used directly on site?

No mathematical proportioning algorithm replaces physical laboratory testing. Mix designs produce target starting proportions that must be verified by laboratory trial mixes to confirm actual workability, 7-day strength, and 28-day compressive strength with locally sourced batch materials.

How are field moisture and water absorption handled?

Mix designs calculate saturated-surface-dry (SSD) quantities. When aggregates in the yard possess free surface moisture or water absorption deficiencies, the mixing water and aggregate batch weights are automatically adjusted in the "Site Adjusted Field Batching" summary.

Developer & REST API Reference

Automate mix proportioning, keyword detection, and library retrieval via JSON endpoints.

GET /api/concrete-types

Returns metadata for all 12 special concrete types and conventional concrete, including total mix counts, primary references, and keyword counts.

GET /api/keywords/{concrete_type}

Returns the full 100-keyword bank for a specific special concrete slug (e.g. geopolymer, uhpc, ecc).

POST /api/design/parse

Parses freeform natural-language text. Returns extracted conventional parameters plus detected_type, confidence, and matched_keywords.

POST /api/design

Executes mix design calculation. Routes conventional inputs to IS 10262 and special types to the literature-anchored reference proposal engine.

GET /api/examples?concrete_type={type}&grade={grade}

Query the 401 solved mix problem library with type, grade, and exposure filters.
